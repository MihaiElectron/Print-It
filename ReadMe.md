# Print-It

## Description

Print-It est un projet réalisé dans le cadre de la formation Développeur Intégrateur Web d'OpenClassrooms.

L'objectif était de développer un carrousel dynamique en JavaScript à partir d'une interface existante. Le projet permet de découvrir les fondamentaux de la programmation JavaScript, la manipulation du DOM et la gestion des interactions utilisateur.

## Objectifs

* Découvrir les bases du langage JavaScript.
* Manipuler le DOM dynamiquement.
* Gérer les événements utilisateurs.
* Développer un carrousel interactif.
* Mettre en place une navigation circulaire entre plusieurs diapositives.

## Technologies utilisées

* HTML5
* CSS3
* JavaScript
* DOM API
* GitHub

## Fonctionnalités

* Navigation via les flèches gauche et droite.
* Génération dynamique des bullet points.
* Mise à jour automatique des images.
* Mise à jour du texte associé aux diapositives.
* Gestion de la diapositive active.
* Navigation circulaire infinie.

## Compétences développées

* JavaScript fondamental
* Manipulation du DOM
* Gestion des événements
* Tableaux JavaScript
* Conditions et logique applicative
* Création de composants interactifs
* Débogage JavaScript

## Lancer le projet

1. Cloner le dépôt.
2. Ouvrir le fichier `index.html` dans un navigateur.
3. Utiliser les flèches de navigation pour parcourir les différentes diapositives.
